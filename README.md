**Zenigram** — модификация Telegram для Android с открытым исходным кодом. Проект ориентирован на спокойный минималистичный интерфейс в стиле Material You, гибкую кастомизацию, функции скрытности и полную чистоту от сторонней аналитики.

---

## 🎨 Возможности

### Студия тем
- **Скругление сообщений:** Плавная регулировка радиуса углов баблов.
- **Цветовая палитра:** Базовые пресеты (Песочный, Графит), поддержка динамических цветов Monet и выбор произвольного цвета через палитру.
- **Кастомизация интерфейса:** Настройка плотности элементов и скорости системных анимаций (0.5x, 1x, 1.5x).

### Типографика
- Встроенный шрифт **Comfortaa** с плавным переключением.
- Гибкая область применения шрифта: весь интерфейс и сообщения либо только элементы управления.

### Видеосообщения (кружочки)
- Удобная центрированная панель управления (переключение камеры, вспышка, зум).
- Быстрое переключение зума в одно касание: **1x, 2x, 5x, 10x**.

### Скрытность и приватность
- Режим призрака: чтение сообщений без отправки отчёта о прочтении.
- Скрытие статуса набора текста.
- Разрешение создания скриншотов в защищённых чатах, каналах и самоуничтожающихся медиа.
- Полное отключение встроенной аналитики, крашлитиков и сторонних трекеров.

### Иконка приложения
- Адаптивные иконки под любую сетку лаунчера (Крафт, Тёмный, Монохром).

### Обновления
- Встроенная проверка актуальных версий и быстрая установка OTA-обновлений напрямую через **GitHub Releases** без сторонних серверов.

## 🛠 Сборка из исходного кода

### Требования
- **JDK:** 17 или 21
- **Android SDK:** API 35, Build-Tools 35.0.0
- **NDK:** r27+

### Инструкция по сборке

1. Клонируйте репозиторий вместе с субмодулями:
   ```bash
   git clone --recursive [https://github.com/Vechoix/Zenigram.git](https://github.com/Vechoix/Zenigram.git)
   cd Zenigram
Запустите скрипт сборки релизного APK:

PowerShell
powershell -ExecutionPolicy Bypass -File .\build_release.ps1
Готовый APK-файл будет сохранён в каталоге APKs/.
