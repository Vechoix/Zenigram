# Zenigram

Zenigram — модификация Telegram для Android с открытым исходным кодом. Проект ориентирован на спокойный минималистичный интерфейс, гибкую настройку оформления, функции скрытности и чистоту от сторонней аналитики.

---

## Возможности

- **Студия тем**
  - Плавная регулировка скругления углов сообщений.
  - Базовые цветовые темы (Песочный, Графит) и выбор произвольного цвета через палитру.
  - Настройка плотности интерфейса и скорости системных анимаций.

- **Типографика**
  - Возможность переключения на шрифт Comfortaa.
  - Выбор области применения шрифта: весь интерфейс и чаты либо только элементы управления.

- **Видеосообщения (кружочки)**
  - Центрированная панель управления (переключение камеры, зум, вспышка).
  - Быстрое переключение зума по нажатию на центральную кнопку: 1x, 2x, 5x, 10x.

- **Скрытность и приватность**
  - Чтение сообщений без отправки статуса прочтения.
  - Скрытие статуса набора текста.
  - Разрешение создания скриншотов в защищенных чатах и каналах.
  - Отключение сбора аналитики и трекеров.

- **Иконка приложения**
  - Адаптивные иконки, отцентрированные под любую сетку лаунчера (Крафт, Тёмный, Монохром).

- **Обновления**
  - Встроенная проверка актуальных версий и установка OTA-обновлений напрямую с GitHub Releases.

## Сборка из исходного кода

### Требования
- JDK 17 или 21
- Android SDK (API 35, Build-Tools 35.0.0, NDK r27+)

### Сборка

1. Клонирование репозитория:
   ```bash
   git clone --recursive https://github.com/Vechoix/Zenigram.git
   cd Zenigram
   ```

2. Сборка релизного APK:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build_release.ps1
   ```
   Итоговый файл будет сохранен в каталоге `APKs/`.
